AI-Driven Job Application Engine

Engineered an AI-driven automation tool using LLM-based code generation to streamline job application workflows; integrated multi-provider LLM failover across Cerebras, Groq, OpenRouter, and DeepSeek.

The problem

Job hunting is repetitive: finding roles, tailoring a CV, and retyping the same answers into long, inconsistent application forms. Free-tier LLMs can do the thinking, but they rate-limit and disappear without warning.

How the system fits together

Five stages. The two highlighted ones are where most of my engineering went.

  1. Job boards & ATSGreenhouse, Lever, Workday and more
  2. Scan · score · tailorRank roles, select the right CV content
  3. LLM routerCerebras · Groq · OpenRouter · DeepSeek, with cooldown + failover
  4. Application fillerFills each page, verifies every write, stops at Submit
  5. Me, on my phoneNotified when a form is ready; I review and submit

Routing that survives free-tier limits

The router treats provider failure as normal. These rules come straight from the code’s own comments and commit history.

SignalResponse
429 rate limitedProvider cools down until its Retry-After, or until midnight for daily caps
402 payment requiredProvider retired for 24 hours
403 model refusedThat model is benched alone; its provider keeps serving others

Why it matters: one failing model never takes a whole provider offline, and one exhausted provider never stalls a run.

Filling applications, with guard rails

Automation that writes into other people’s forms has to be careful. The filler is built around not being wrong.

Verified

Every write is checked

Values are read back after being entered, so a field that silently rejected input is caught rather than assumed.

Scoped

Only the right page

Writes are bound to the page and document that own them, so a re-render mid-fill can’t send an answer to the wrong place.

Honest

Never claims what isn’t true

Answers carry their provenance, and personal facts are asked for rather than guessed (for example, it never claims you live near an office).

Human in the loop: it fills every page up to the final Submit, then hands off. The last decision stays mine.
